# 🌸 Pink Fractal Tree Animation

A beautiful animated Pink Fractal Tree created using Python.

## ✨ Features
- Automatic tree generation
- Recursive branching algorithm
- Pink flower effects
- Animated GIF output
- Black background graphics

## 🛠️ Technologies Used
- Python
- NumPy
- Pillow

## 📦 Installation

```bash
pip install numpy pillow
```

## ▶️ Run the Project

```bash
python pink_tree_auto_animation.py
```
